# Course_project_3
## Описание проекта
Приложение для анализа транзакций. Генерирует JSON-данные для веб-страниц,<br/>
формирует Excel-отчеты, а также предоставляет другие сервисы.<br/>
Это курсовой проект студента курса [Python - разработчик](https://sky.pro/courses/programming/python-web-course#giftpopup)
на обучающей платформе [Skypro](https://sky.pro/).
## Структура проекта
* [main.py](main.py) - модуль с функцией main, которая формирует основную логику проекта и связывает<br/>
функциональности между собой
* src
  + [data_capture.py](src/data_capture.py) - модуль с функциями, анализирующими двумерные таблицы
с транзакциями<br/>и предоставляющими топ операций по платежам, данные по каждой платёжной карте и пр.<br/>
  + [decorators_class.py](src/decorators_class.py) - модуль с классом-декоратором, добавляющим функциям
из модуля отчётов<br/>возможность записи отчёта в JSON-файл, название которого принимает в качестве аргумента
  + [external_requests.py](src/external_requests.py) - модуль с функциями, запрашивающими на удалённом ресурсе<br/>
курс отслеживаемых валют и котировки акций
  + [logger.py](src/logger.py) - модуль с функциями, предоставляющими возможность логирования всего функционала
  + [readers.py](src/readers.py) - модуль с функцией, читающей EXCEL-файл и возвращающей двумерную таблицу
  + [reports.py](src/reports.py) - модуль с функцией, предоставляющей отчёт по тратам в определённой категории
  + [selection_util.py](src/selection_util.py) - модуль с функцией фильтрации двумерных таблиц
  + [services.py](src/services.py) - модуль с функцией-поиском транзакций по выражениям в категории или в описании
  + [views.py](src/views.py) - модуль с основной функцией раздела Главная страница
* tests
  + test_data_capture.py - модуль с тестами для модуля data_capture.py
  + test_decorators_class.py - модуль с тестами для модуля decorators_class.py
  + test_external_requests.py - модуль с тестами для модуля external_requests.py
  + test_readers.py - модуль с тестами для модуля readers.py
  + test_reports.py - модуль с тестами для модуля reports.py
  + test_services.py - модуль с тестами для функций модуля services.py
  + test_views.py - модуль с тестами для модуля views.py

В проект добавлена директория [logs](logs) для ведения отчётов по работе функционала проекта.

## Установка
```commandline
poetry install
```
## Тестирование
Для разработчика:
```commandline
pytest
```
## Пример использования
Для того, чтобы запустить проект, необходимо сначала установить зависимости.<br/>
Затем нужно запустить файл `main.py`:
```commandline
python main.py
```
